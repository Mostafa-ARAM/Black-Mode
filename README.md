# Black Mode — GitHub Pages

صفحه تماس موبایلی لوکس Black Mode با HTML، CSS و JavaScript.

آیکن‌های Telegram، Instagram و WhatsApp به صورت SVG داخل HTML هستند؛ بنابراین به Font Awesome، CDN یا سرویس خارجی برای آیکن‌ها نیاز ندارد.

دکمه «ذخیره مخاطب» یک فایل استاندارد VCF می‌سازد تا کاربر آن را باز کرده و به مخاطبین اضافه کند.

برای GitHub Pages: فایل‌ها را در Repository قرار دهید و از Settings → Pages، شاخه main و پوشه root را فعال کنید.
